## cypress:10.11.0

Образ с Cypress версии 10.11.0.

Содержит версии:
- node: 16.16.0
- chromium: latest

Как собрать:
Из корневой дирректории выполнить команду:
```bash
docker build -t cypress:10.11.0 ./images
```

Архитектура (amd или arm) зависит от системы, на которой происходит билд.
Запуск команды через buildx или с добавлением флага --platform (linux/amd64 | linux/arm64) приводит к ошибке
